import { Steps } from "@astrojs/starlight/components"

需要 Node.js 22.19 或更高版本，这是 CLI 所用 Effect
Node 适配器要求的版本。该版本也提供热重载所需的 `module.registerHooks`。

<Steps>

1. 创建项目并安装依赖：

   ```sh
   npx @graftland/cli create my-app --install
   cd my-app
   ```

   除了 `package.json`，项目还包含三个文件：

   | 文件         | 用途                                 |
   | ------------ | ------------------------------------ |
   | `graft.yml`  | 配置文件，指定要加载的插件及其配置。 |
   | `hello.mjs`  | 示例插件。                           |
   | `.gitignore` | 忽略 `node_modules` 和 `.env`。      |

2. 启动应用并监听文件变化：

   ```sh
   npx graft start --watch
   ```

   `hello` 插件会输出 `Hello from Graft!`。进程会持续运行，直到你按下

   <kbd>Ctrl</kbd>+<kbd>C</kbd>，此时 Graft 会卸载所有插件。

3. 在应用运行期间修改配置。打开 `graft.yml`，修改消息：

   ```yaml
   - id: hello
     name: ./hello.mjs
     config:
       message: Hello again!
   ```

   保存后，Graft 会卸载 `hello`，再用新消息重新加载。你会先看到
   `Hello plugin stopped`，然后是 `Hello again!`。

4. 在应用运行期间修改代码。编辑
   `hello.mjs`（例如让它输出两次消息），然后保存。Graft 会导入模块的新版本，用它替换正在运行的插件。如果新代码导入失败，旧版本会继续运行，Graft 会把错误记录到日志中。

</Steps>

## 示例插件

```js title="hello.mjs"
import { Plugin } from "@graftland/graft"
import { Effect, Schema } from "effect"

// Module evaluation only defines the plugin; its activation owns all resources.
export default Plugin.make({
	name: "hello",
	config: Schema.Struct({ message: Schema.String }),
	apply: ({ message }) =>
		Effect.acquireRelease(Effect.logInfo(message), () =>
			Effect.logInfo("Hello plugin stopped"),
		),
})
```

插件模块通过默认导出或名为 `plugin`
的导出提供插件。导入模块时不应启动任何工作。连接、定时器和服务器都应在 `apply`
内启动，以便 Graft 能够释放这些资源。参见[插件](../plugins/)。

## 从 npm 添加插件

```sh
npx graft add graft-plugin-review
```

`graft add` 使用项目的包管理器安装包。如果安装失败，它会将 `package.json`
和锁文件恢复原状。安装和恢复期间，不要编辑项目文件或运行其他安装命令。回滚会覆盖修改，不会合并修改。参见[安装的独占性与恢复](../cli/#包管理器)。然后在
`graft.yml` 中添加该插件的配置项。`name` 可以使用短名称
`review`。Graft 会依次查找 `review`、`@graftland/plugin-review` 和
`graft-plugin-review`。参见[配置文件](../config-file/)。
