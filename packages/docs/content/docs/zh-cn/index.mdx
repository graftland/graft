## 三项承诺

<CardGrid>
	<Card title="砧木">
		服务就是 Effect 的 <code>Context</code> 键。挂载在 <code>requires</code>{" "}
		中列出所需条目，由编译器检查。见<a href="mounting/">挂载</a>。
	</Card>
	<Card title="修剪">
		每个挂载都有自己的 <code>Scope</code>
		。依赖消失时，使用它的部分先停止，然后才关闭它的资源。失败保留完整的{" "}
		<code>Cause</code>。见<a href="lifecycle/">生命周期</a>。
	</Card>
	<Card title="可用性">
		服务存在时读取它，或者只在它存在时运行工作。撤回会中断工作，而不是留下过期的值。见
		<a href="availability/">服务可用性</a>。
	</Card>
</CardGrid>

## 第一次挂载

```ts import.meta.vitest name="index: a first mount"
import { Context, Effect, Layer, Option, Stream } from "effect"

import { Graft, Mount } from "@graftland/graft"

class Greeter extends Context.Service<
	Greeter,
	{ readonly greet: (name: string) => Effect.Effect<void> }
>()("app/Greeter") {}

const greeter = Layer.effect(
	Greeter,
	Effect.succeed({ greet: (name) => Effect.log(`Hello, ${name}!`) }),
)

const state = await Effect.runPromise(
	Effect.gen(function* () {
		const mount = yield* Graft.mount(greeter, { name: "greeter" })
		yield* mount.await
		return yield* Stream.runHead(mount.state)
	}).pipe(Effect.scoped, Effect.provide(Graft.layer)),
)
state // => Option.some(Mount.MountState.Active())
```

## 一个包

Graft 只有一个包 `@graftland/graft`，`effect` 是它的 peer 依赖。

| 入口            | 内容                                   |
| --------------- | -------------------------------------- |
| `graft`         | `Graft`、`Mount` 与 `Release`。        |
| `graft/rpc`     | 通过任意 `effect/rpc` 协议的远程服务。 |
| `graft/node`    | Node.js 的子进程和 worker 协议。       |
| `graft/testing` | 供测试使用的内存协议。                 |

从更早的版本升级？见[发布流程](releases/)。
