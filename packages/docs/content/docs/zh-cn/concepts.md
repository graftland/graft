Graft 只有三个术语。每个术语都有一页说明其余规则。

| 术语                    | 含义                                                     | 了解更多                 |
| ----------------------- | -------------------------------------------------------- | ------------------------ |
| **图（Graph）**         | 运行中的服务依赖图，由 `Graft.layer` 提供。              | [挂载](../mounting/)     |
| **挂载（Mount）**       | 放进图里的一个 Layer。依赖可用期间，它被构建并保持运行。 | [挂载](../mounting/)     |
| **发布（Publication）** | 从 Layer 外部放进图里的一个值，例如配置。                | [发布](../publications/) |

**服务**是带值的 Effect `Context`
键。图里的服务可以由挂载发布，可以直接发布，也可以由构建 `Graft.layer`
时的环境提供。

## 各部分如何关联

1. 挂载**需要**若干条目：服务，以及 `Context.Reference`
   键，其中一些可以是可选的。
2. 所有必需条目都可用时，Graft **构建**这个 Layer。
3. 构建完成后，Graft **发布** Layer 输出上下文里的每个服务。
4. 某个必需条目**变化或消失**时，Graft 先停下所有使用这些服务的挂载，再释放 Layer，然后重新构建。
5. 发布的 **`set`** 替换它的值，所有需要它的挂载随之重建。

挂载构成一棵树：在一个挂载的 Layer 里创建的挂载，是它的子挂载。关闭 scope 会卸载其中创建的一切。

## 保证

| 保证                       | 来源                                                   |
| -------------------------- | ------------------------------------------------------ |
| 依赖经过声明并由编译器检查 | `requires` 与 Layer 的输入类型对照检查。               |
| 消费者先于提供者停止       | [生命周期](../lifecycle/#拆除顺序)中的租约与拆除顺序。 |
| 资源总会被释放             | 每个挂载拥有一个 `Scope`，它的 fiber 都归它所有。      |
| 失败保留完整的 `Cause`     | [失败与重试](../failures-retry/)。                     |
| 变化以原子方式被接受       | 发布、撤回和依赖检查共用一个事务。                     |

## 构建于 Effect 之上

Graft 不引入平行的概念体系，而是直接映射到 Effect：

| 在 Graft 中    | 在 Effect 中                                       |
| -------------- | -------------------------------------------------- |
| 挂载           | 在 `Scope` 中构建的 `Layer`                        |
| 服务           | `Context` 键                                       |
| 发布的值       | 带值的 `Context` 键                                |
| 后台工作       | 归挂载所有的 `Fiber`                               |
| 重试           | `Schedule`                                         |
| 每个挂载的设置 | `Context.Reference` 与 [Intercept](../intercepts/) |
| 隔离           | 领域，见[隔离](../isolation/)                      |

Graft 只补充 Effect 所没有的部分：会来来去去的服务、对此外做出反应的 Layer 图，以及跨图的安全拆除。
