<div class="graft-manifesto">
	<p>
		<strong>Layers are not fixed at startup. They are grown.</strong>
	</p>
	<p>
		A layer arrives when its dependencies do, bears its services while it runs,
		and is pruned when a dependency disappears. The application keeps standing
		while its branches change.
	</p>
	<p>
		Graft adds only what Effect does not have: a graph of layers that come and
		go, and the guarantees that make those changes safe.
	</p>
</div>

## Three promises

<CardGrid>
	<Card title="Rootstock">
		Services are Effect <code>Context</code> keys. A mount lists what it needs
		in <code>requires</code>, and the compiler checks the list. See{" "}
		<a href="mounting/">mounting</a>.
	</Card>
	<Card title="Pruning">
		Each mount runs in its own <code>Scope</code>. When a requirement goes away,
		its dependents stop first, then its resources close. A failure keeps its
		full <code>Cause</code>. See <a href="lifecycle/">lifecycle</a>.
	</Card>
	<Card title="Availability">
		Read a service while it exists, or run work only while it is published.
		Withdrawal interrupts the work instead of leaving a stale value behind. See{" "}
		<a href="availability/">availability</a>.
	</Card>
</CardGrid>

## A first mount

```ts import.meta.vitest name="index: a first mount"
import { Context, Effect, Layer, Option, Stream } from "effect"

import { Graft, Mount } from "@graftland/graft"

class Greeter extends Context.Service<
	Greeter,
	{ readonly greet: (name: string) => Effect.Effect<void> }
>()("app/Greeter") {}

const greeter = Layer.effect(
	Greeter,
	Effect.succeed({ greet: (name) => Effect.log(`Hello, ${name}!`) }),
)

const state = await Effect.runPromise(
	Effect.gen(function* () {
		const mount = yield* Graft.mount(greeter, { name: "greeter" })
		yield* mount.await
		return yield* Stream.runHead(mount.state)
	}).pipe(Effect.scoped, Effect.provide(Graft.layer)),
)
state // => Option.some(Mount.MountState.Active())
```

## One package

Graft is a single package, `@graftland/graft`, with `effect` as a peer
dependency.

| Entry           | What it holds                                   |
| --------------- | ----------------------------------------------- |
| `graft`         | `Graft`, `Mount` and `Release`.                 |
| `graft/rpc`     | Remote services over any `effect/rpc` protocol. |
| `graft/node`    | Child process and worker protocols for Node.js. |
| `graft/testing` | An in-memory protocol for tests.                |

Upgrading from an earlier version? See [Releases](releases/).
