## 三項承諾

<CardGrid>
	<Card title="砧木">
		服務就是 Effect 的 <code>Context</code> 鍵。掛載在 <code>requires</code>{" "}
		中列出所需項目，由編譯器檢查。見<a href="mounting/">掛載</a>。
	</Card>
	<Card title="修剪">
		每個掛載都有自己的 <code>Scope</code>
		。相依項目消失時，使用它的部分先停止，然後才關閉它的資源。失敗保留完整的{" "}
		<code>Cause</code>。見<a href="lifecycle/">生命週期</a>。
	</Card>
	<Card title="可用性">
		服務存在時讀取它，或者只在它存在時執行工作。撤回會中斷工作，而不是留下過期的值。見
		<a href="availability/">服務可用性</a>。
	</Card>
</CardGrid>

## 第一次掛載

```ts import.meta.vitest name="index: a first mount"
import { Context, Effect, Layer, Option, Stream } from "effect"

import { Graft, Mount } from "@graftland/graft"

class Greeter extends Context.Service<
	Greeter,
	{ readonly greet: (name: string) => Effect.Effect<void> }
>()("app/Greeter") {}

const greeter = Layer.effect(
	Greeter,
	Effect.succeed({ greet: (name) => Effect.log(`Hello, ${name}!`) }),
)

const state = await Effect.runPromise(
	Effect.gen(function* () {
		const mount = yield* Graft.mount(greeter, { name: "greeter" })
		yield* mount.await
		return yield* Stream.runHead(mount.state)
	}).pipe(Effect.scoped, Effect.provide(Graft.layer)),
)
state // => Option.some(Mount.MountState.Active())
```

## 一個套件

Graft 只有一個套件 `@graftland/graft`，`effect` 是它的 peer 相依項目。

| 入口            | 內容                                   |
| --------------- | -------------------------------------- |
| `graft`         | `Graft`、`Mount` 與 `Release`。        |
| `graft/rpc`     | 透過任意 `effect/rpc` 協定的遠端服務。 |
| `graft/node`    | Node.js 的子行程和 worker 協定。       |
| `graft/testing` | 供測試使用的記憶體協定。               |

從更早的版本升級？見[發布流程](releases/)。
