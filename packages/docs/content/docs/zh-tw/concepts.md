Graft 只有三個術語。每個術語都有一頁說明其餘規則。

| 術語                    | 說明                                                         | 延伸閱讀                 |
| ----------------------- | ------------------------------------------------------------ | ------------------------ |
| **圖（Graph）**         | 執行中的服務相依圖，由 `Graft.layer` 提供。                  | [掛載](../mounting/)     |
| **掛載（Mount）**       | 放進圖裡的一個 Layer。相依項目可用期間，它被建置並保持執行。 | [掛載](../mounting/)     |
| **發布（Publication）** | 從 Layer 外部放進圖裡的一個值，例如設定。                    | [發布](../publications/) |

**服務**是帶值的 Effect `Context`
鍵。圖裡的服務可以由掛載發布，可以直接發布，也可以由建置 `Graft.layer`
時的環境提供。

## 各部分如何關聯

1. 掛載**需要**若干項目：服務，以及 `Context.Reference`
   鍵，其中一些可以是可選的。
2. 所有必要項目都可用時，Graft **建置**這個 Layer。
3. 建置完成後，Graft **發布** Layer 輸出內容中的每個服務。
4. 某個必要項目**變化或消失**時，Graft 先停下所有使用這些服務的掛載，再釋放 Layer，然後重新建置。
5. 發布的 **`set`** 替換它的值，所有需要它的掛載隨之重建。

掛載構成一棵樹：在一個掛載的 Layer 裡建立的掛載，是它的子掛載。關閉 scope 會卸載其中建立的一切。

## 保證

| 保證                           | 來源                                                   |
| ------------------------------ | ------------------------------------------------------ |
| 相依項目經過宣告並由編譯器檢查 | `requires` 與 Layer 的輸入型別對照檢查。               |
| 消費者先於提供者停止           | [生命週期](../lifecycle/#拆除順序)中的租約與拆除順序。 |
| 資源一定會被釋放               | 每個掛載擁有一個 `Scope`，它的 fiber 都歸它所有。      |
| 失敗保留完整的 `Cause`         | [失敗與重試](../failures-retry/)。                     |
| 變化以原子方式被接受           | 發布、撤回和相依檢查共用一筆交易。                     |

## 建立在 Effect 之上

Graft 不引入平行的概念體系，而是直接對應到 Effect：

| 在 Graft 中    | 在 Effect 中                                       |
| -------------- | -------------------------------------------------- |
| 掛載           | 在 `Scope` 中建置的 `Layer`                        |
| 服務           | `Context` 鍵                                       |
| 發布的值       | 帶值的 `Context` 鍵                                |
| 背景工作       | 歸掛載所有的 `Fiber`                               |
| 重試           | `Schedule`                                         |
| 每個掛載的設定 | `Context.Reference` 與 [Intercept](../intercepts/) |
| 隔離           | 領域，見[隔離](../isolation/)                      |

Graft 只補充 Effect 所沒有的部分：會來來去去的服務、對此外做出反應的 Layer 圖，以及跨圖的安全拆除。
