import { Steps } from "@astrojs/starlight/components"

需要 Node.js 22.19 或更新版本，這是 CLI 所用 Effect
Node 轉接器要求的版本。該版本也提供熱重載所需的 `module.registerHooks`。

<Steps>

1. 建立專案。按 <kbd>Enter</kbd> 接受每個預設值；命令會安裝相依套件：

   ```sh
   npm create @graftland@latest my-app
   cd my-app
   ```

   先從這幾個檔案開始：

   | 檔案            | 用途                                |
   | --------------- | ----------------------------------- |
   | `graft.yml`     | 設定檔，指定要載入的外掛及其設定。  |
   | `src/hello.ts`  | 範例外掛。                          |
   | `tsconfig.json` | 供 `npm run typecheck` 做型別檢查。 |

   [`graft create`](../cli/#graft-create)
   列出了所有問題、其他範本，以及跳過提問的選項。

2. 啟動應用程式並監看檔案變更：

   ```sh
   npm run dev
   ```

   `hello` 外掛會輸出 `Hello from Graft!`。行程會持續執行，直到你按下

   <kbd>Ctrl</kbd>+<kbd>C</kbd>，此時 Graft 會卸載所有外掛。

3. 在應用程式執行期間修改設定。開啟 `graft.yml`，修改訊息：

   ```yaml
   - id: hello
     name: ./src/hello.ts
     config:
       message: Hello again!
   ```

   儲存後，Graft 會卸載 `hello`，再用新訊息重新載入。你會先看到
   `Hello plugin stopped`，然後是 `Hello again!`。

4. 在應用程式執行期間修改程式碼。編輯
   `src/hello.ts`（例如讓訊息輸出兩次）並儲存。Graft 會匯入模組的新版本，並用它取代執行中的外掛。如果新程式碼匯入失敗，舊版本會繼續執行，Graft 並記錄錯誤。

</Steps>

## 範例外掛

```ts title="src/hello.ts"
import { Effect, Schema } from "effect"

import { Plugin } from "@graftland/graft"

// Module evaluation only defines the plugin; its activation owns all resources.
export default Plugin.make({
	name: "hello",
	config: Schema.Struct({ message: Schema.String }),
	apply: ({ message }) =>
		Effect.acquireRelease(Effect.logInfo(message), () =>
			Effect.logInfo("Hello plugin stopped"),
		),
})
```

Node 會移除型別後直接執行這個 TypeScript 檔案，因此不需要建置步驟。外掛模組以預設匯出，或以名為
`plugin` 的匯出來提供它的外掛。匯入模組時不得啟動任何東西。請在 `apply`
內開啟連線、計時器和伺服器，這樣 Graft 才能釋放它們。請參閱[外掛](../plugins/)。

## 從 npm 新增外掛

```sh
npx graft add graft-plugin-review
```

`graft add` 使用專案的套件管理器安裝套件。如果安裝失敗，它會把 `package.json`
和鎖定檔還原成原來的樣子。安裝或復原期間，請不要編輯專案檔案，也不要執行其他安裝程式。還原會覆寫變更，不會合併它們。請參閱[安裝的所有權與還原](../cli/#套件管理器)。接著在
`graft.yml` 中為該外掛新增一個項目。它的 `name` 可以是短名稱
`review`，Graft 會依序尋找 `review`、`@graftland/plugin-review` 和
`graft-plugin-review`。請參閱[設定檔](../config-file/)。
