# @graftland/loader

Loads plugins from a list of entries or a YAML config file.

```sh
npm install @graftland/loader effect
```

`Include` keeps entries in a YAML file and writes edits back to it, `Loader`
edits them at run time, and `ModuleResolver` turns entry names into plugins.
