`graft` 命令：`start`、`create`、`add` 和 `remove`。

```sh
npm install @graftland/cli effect
```

用 `npx @graftland/cli create my-app --install` 创建项目，然后用
`npx graft start --watch` 运行它。需要 Node.js 22.19 或更高版本。
