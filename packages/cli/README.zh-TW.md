# @graftland/cli

[English](https://github.com/graftland/graft/blob/main/packages/cli/README.md) |
[简体中文](https://github.com/graftland/graft/blob/main/packages/cli/README.zh-CN.md)
| 繁體中文

`graft` 命令：`start`、`create`、`add` 和 `remove`。

```sh
npm install @graftland/cli @graftland/graft @graftland/loader effect
```

用 `npm create @graftland@latest my-app` 建立專案，它執行的是同一個 `create`
命令。然後用 `npm run dev` 執行它。需要 Node.js 22.19 或更新版本。
