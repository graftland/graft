# @graftland/cli

[English](https://github.com/graftland/graft/blob/main/packages/cli/README.md) |
[简体中文](https://github.com/graftland/graft/blob/main/packages/cli/README.zh-CN.md)
| 繁體中文

`graft` 命令：`start`、`create`、`add` 和 `remove`。

```sh
npm install @graftland/cli effect
```

用 `npx @graftland/cli create my-app --install` 建立專案，然後用
`npx graft start --watch` 執行它。需要 Node.js 22.19 或更新版本。
