# @graftland/hmr

Reloads plugin modules on Node.js without restarting the process.

```sh
npm install @graftland/hmr effect
```

`Hmr.make` gives an importer for the loader, and `reload` and `watch` to replace
plugins with new code. Needs Node.js 22.15 or later.
