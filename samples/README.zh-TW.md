# 範例

[English](README.md) | [简体中文](README.zh-CN.md) | 繁體中文

每個範例都是一個可以執行的程式，各自放在獨立的套件裡。

## 從這裡開始

剛接觸 Graft？請依序閱讀。每個範例都是一個簡短的檔案，只講一個概念，會印出執行過程，並提供可以動手試試的建議。

| 範例                               | 你將學到                                                               |
| ---------------------------------- | ---------------------------------------------------------------------- |
| [01 · Hello](01-hello)             | 定義外掛、載入外掛、修改它的設定、卸載它。                             |
| [02 · Services](02-services)       | 在一個外掛中發布服務，在另一個外掛中使用它，後者會等待服務出現。       |
| [03 · Events](03-events)           | 外掛卸載時會自動消失的事件處理器。                                     |
| [04 · Failures](04-failures)       | 失敗的外掛、重試排程，以及屬於外掛的背景任務。                         |
| [05 · Config file](05-config-file) | 用 `graft start --watch` 從 `graft.yml` 執行外掛，並在執行時編輯它們。 |

## 真實情境的應用

這些範例把基礎概念組合成更大的程式。每個 README 都從一個你原本需要手動解決的問題開始，然後展示 Graft 如何處理它。

| 範例                                 | 情境                                               | 展示內容                                                                                |
| ------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [chat-bot](chat-bot)                 | 一個聊天機器人，它的指令和過濾器都是外掛。         | 由外掛擁有的事件處理器、相依條件控管、原地更新、只影響局部的失敗。                      |
| [checkout-upgrade](checkout-upgrade) | 在定價升級和資料庫容錯移轉期間執行的訂單處理器。   | 高負載下的 `Graft.replace` 與重新設定、有序的拆除、排空進行中的工作。                   |
| [http-gateway](http-gateway)         | 一個真實的 HTTP 伺服器，它的路由來自 `graft.yml`。 | `graft start --watch`、服務期間的設定編輯與熱重載、`Pending` 路由、即時的 fork 樹。     |
| [saas-tenants](saas-tenants)         | 同一組外掛為多個租戶提供服務。                     | 每個租戶各自的 `isolate` 與 `intercept`、帶有租戶專屬設定的共用服務、租戶的加入與退出。 |
| [market-feed](market-feed)           | 一個建立在不穩定交易所之上的行情資料管線。         | 受監督的背景任務、重試排程、`Pending` 與 `Failed` 狀態、可選的相依。                    |
| [remote-worker](remote-worker)       | 宿主呼叫本機子行程中的服務。                       | 共用契約、跨行程服務、關閉時確認行程退出。                                              |

## 執行範例

範例會匯入工作區中的套件，Node 從這些套件的建置產物中載入它們。請在儲存庫根目錄執行：

```sh
devenv shell -- pnpm build
devenv shell -- pnpm --filter @graftland/sample-hello start
```

每個範例的 README 都給出了它的具體指令。`05-config-file` 和 `http-gateway`
會一直執行，直到你按下
<kbd>Ctrl</kbd>+<kbd>C</kbd>。其他範例印完過程後就會結束。

`devenv shell -- pnpm test` 會把範例的測試和工作區的其他測試一起執行。
