# 範例

繁體中文

每個範例都是自己套件裡的小程式。依序閱讀；每個範例只講一個概念，並印出會發生什麼事。

| 範例                                  | 你會學到                                               |
| ------------------------------------- | ------------------------------------------------------ |
| [01 · 掛載 Layer](01-mount-layer)     | 掛載一個一般 `Layer`，使用它的服務，然後釋放它。       |
| [02 · 發布與重建](02-publish-rebuild) | 發布一個值，並在它變化時重建需要它的掛載。             |
| [03 · 失敗與重試](03-failure-retry)   | 失敗的掛載、重試排程，以及歸掛載所有的背景 fiber。     |
| [04 · 租戶](04-tenants)               | 用 `isolate` 和 `intercept` 讓多個租戶共用一套 Layer。 |
| [05 · 遠端](05-remote)                | 透過 `effect/rpc` 提供遠端服務，並從另一個圖連線它。   |
| [06 · 重連](06-reconnect)             | 中斷的連線會撤回遠端服務；重新連線後它們又會回來。     |

## 執行範例

在儲存庫根目錄：

```sh
devenv shell -- pnpm build
devenv shell -- pnpm --filter @graftland-samples/01-mount-layer start
```

每個 README 都給出自己的確切指令。範例 01–04 印出它們的過程後結束。範例 05 和 06 使用
`@graftland/graft/testing` 的記憶體協定，所以它們也會自己結束。
