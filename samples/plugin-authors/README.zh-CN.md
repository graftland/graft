# 插件作者夹具

这些包演示通过公开导出发布插件。Alice 的 echo 和 Bob 的 counter 分别拥有契约包与实现包。一方 echo 夹具运行完全相同的测试工具。不兼容包需要缺失的操作和更新的 Node 运行时。作者名用于标识测试夹具，不代表独立真人采用。

在仓库根目录运行：

```sh
devenv shell -- pnpm build
devenv shell -- node scripts/packed-ecosystem.mjs
```

脚本打包发布副本，在临时消费项目中安装，针对已安装声明编译各作者代码，生成并验证清单，再打包和安装作者包。它运行只读元数据的 CLI 检查，拒绝不兼容包，并在 Worker 和 Local 上验证可移植值、业务错误、远端缺陷、探针、取消和终止后的传输失败。三个兼容包都必须通过。不使用工作区源码别名或私有导入。脚本结束时删除临时项目。

`pnpm test` 也运行此验证。

Alice 的契约包含自定义运行时检查。发布工具读取操作身份，不序列化 schema。验证会检查每个契约包的目录摘要、拒绝字节变化后的包来源冲突，并在写入前拒绝清单摘要的自引用。

独立修改某位作者的实现和契约，再运行脚本。发布自己的包时，维护 `engines.node`
和 peer 依赖，声明放置需求，并在打包前运行
`graft remote manifest`。来源记录包的字节；外部运行时依赖不会被捕获或固定。
