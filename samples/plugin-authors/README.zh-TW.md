# 外掛作者夾具

這些套件示範透過公開匯出發布外掛。Alice 的 echo 與 Bob 的 counter 分別擁有契約套件與實作套件。第一方 echo 夾具執行完全相同的測試工具。不相容套件需要缺失的操作與更新的 Node 執行環境。作者名稱用於識別測試夾具，不代表獨立真人採用。

在儲存庫根目錄執行：

```sh
devenv shell -- pnpm build
devenv shell -- node scripts/packed-ecosystem.mjs
```

腳本封裝發布副本，在暫存消費專案中安裝，針對已安裝宣告編譯各作者程式碼，產生並驗證清單，再封裝和安裝作者套件。它執行僅讀取中繼資料的 CLI 檢查，拒絕不相容套件，並在 Worker 與 Local 上驗證可攜值、業務錯誤、遠端缺陷、探針、取消與終止後的傳輸失敗。三個相容套件都必須通過。不使用工作區原始碼別名或私有匯入。腳本結束時刪除暫存專案。

`pnpm test` 也執行此驗證。

Alice 的契約包含自訂執行期檢查。發布工具讀取操作身分，不序列化 schema。驗證會檢查每個契約套件的目錄摘要、拒絕位元組變更後的套件來源衝突，並在寫入前拒絕清單摘要的自我參照。

獨立修改某位作者的實作與契約，再執行腳本。發布自己的套件時，維護 `engines.node`
與 peer 相依套件，宣告放置需求，並在封裝前執行
`graft remote manifest`。來源記錄套件的位元組；外部執行期相依套件不會被擷取或固定。
